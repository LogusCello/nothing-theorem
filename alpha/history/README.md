# Original development drafts

`2026-10-drafts/alpha/` and `2026-10-drafts/euler/` preserve the supplied development folders verbatim. They are included to retain the formula choices, author's explanations, alternative calculations, and earlier interpretations without silently rewriting their history.

**These are historical drafts, not the current documentation.** Their publication instructions are superseded. In particular, the claims about exact finite hashing costs, the phi partner, guaranteed holes, calibrated chance percentages, and an independent physical prediction need the corrections in [the current alpha note](../README.md). Their references and historical benchmark claims were not independently source-verified in this review.

The active reproducibility command is `python3 alpha/alpha_check.py` from the repository root. Historical scripts are not included in `run_all.py`; some run slower dictionary-based experiments. No archive files need to be copied over the active files.
